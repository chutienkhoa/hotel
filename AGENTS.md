# Coding Rules

Before implementing or modifying code, read the applicable documents in `docs/coding-rules/`:

- `architecture.md` for project architecture.
- `coding-standards.md` for general code conventions.
- `api-standards.md` for API changes.
- `database-standards.md` for persistence or migration changes.
- `sql.md` for sql coding convention.
- `testing-standards.md` for test changes.
- `security-standards.md` for authentication, authorization, or sensitive-data changes.

Apply only the documents relevant to the task.
