# Coding Standards

- Prefer clear, small, cohesive units of code.
- Keep naming consistent with surrounding code.
- Avoid unrelated refactors in a focused change.
- Keep formatting consistent and remove unused imports.
- Do not duplicate logic when an existing abstraction is suitable.
- Add standard JavaDoc to every declared Java class, interface, enum, record, constructor, and method; describe its purpose and include `@param`, `@return`, or `@throws` tags when applicable.
